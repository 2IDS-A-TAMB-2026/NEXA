# NEXA
 
<img width="200" height="200" alt="logo nexa (4)" src="https://github.com/user-attachments/assets/60951e43-2968-4bca-8548-6fcffda0d427" />

> Solução tecnológica para monitoramento do uso de Equipamentos de Proteção Individual (EPIs), garantindo segurança, prevenção de acidentes e conformidade em ambientes de trabalho. 

 

# Problema 

Falta de fiscalização eficiente no uso de EPIs  

Alto índice de acidentes de trabalho por uso incorreto ou ausência de equipamentos  

Processos manuais de verificação são falhos e custosos  

Dificuldade em registrar e acompanhar ocorrências em tempo real  

 

# Objetivo 

Criar uma solução inteligente para monitoramento automático de EPIs  

Utilizar visão computacional para identificar o uso correto dos equipamentos  

Gerar alertas em tempo real em casos de não conformidade  

Fornecer dados e relatórios para tomada de decisão  

Promover segurança, prevenção e redução de riscos

Indústrias  

Construção Civil

Empresas logísticas  

Hospitais e clínicas  

 

 # Funcionalidades 

Monitoramento em tempo real

Identificação de funcionários  

Alertas de não conformidade  

Registro de ocorrências  

Dashboard com indicadores

Integração com câmeras  

 

 # Tecnologias Utilizadas 

## Linguagens

## Componentes

Integração com câmeras (CFTV/IP)  

 

 # Funcionamento do Sistema 

Captura de imagem: câmeras monitoram o ambiente em tempo real  

Detecção: a IA identifica pessoas e EPIs presentes  

Análise: o sistema verifica se os EPIs obrigatórios estão sendo utilizados  

Registro: os dados são armazenados no banco de dados  

Alerta: em caso de irregularidade, o sistema gera notificações

 # NEXA
 
<img width="200" height="200" alt="logo nexa (4)" src="https://github.com/user-attachments/assets/60951e43-2968-4bca-8548-6fcffda0d427" />

>Technological solution for monitoring the use of Personal Protective Equipment (PPE), ensuring safety, accident prevention, and compliance in work environments. 

 

 # Problem 

Lack of efficient supervision in the use of PPE  

High rate of workplace accidents due to incorrect use or absence of equipment  

Manual verification processes are flawed and costly  

Difficulty in recording and tracking occurrences in real time  

 

 # Objective 

Create an intelligent solution for automatic PPE monitoring  

Use computer vision to identify the correct use of equipment  

Generate real-time alerts in cases of non-compliance  

Provide data and reports for decision-making  

Promote safety, prevention, and risk reduction  

 

 # Target Audience 

Industries  

Construction  

Agribusiness  

Logistics companies  

Hospitals and clinics  

 

 # Features 

Real-time monitoring  

Automatic PPE detection  

Employee identification  

Non-compliance alerts  

Incident logging  

Dashboard with indicators  

Reports and history  

Camera integration  

 

# Technologies Used 

## Languages 

HTML  

CSS  

JavaScript  

PHP  

MySQL  

Flutter  

## Components 

REST API  

Computer Vision (AI)  

Camera integration (CCTV/IP)  

 

 # System Operation 

Image capture: cameras monitor the environment in real time  

Detection: AI identifies people and PPE present  

Analysis: the system checks whether required PPE is being used  

Recording: data is stored in the database  

Alert: in case of irregularities, the system generates notifications
